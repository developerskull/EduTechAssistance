## 🔧 Setup Instructions

### Step 1: Get Your Gemini API Key

1. **Visit Google AI Studio**: https://makersuite.google.com/app/apikey
2. **Sign in** with your Google account
3. **Create API Key**: Click "Create API Key" button
4. **Copy the key**: Save it securely (you'll need it in the next step)

### Step 2: Configure the API Key

1. **Open the backend environment file**: `python-backend/.env`
2. **Replace the placeholder**:
   ```
   # Change this line:
   GEMINI_API_KEY=your_gemini_api_key_here
   
   # To your actual API key:
   GEMINI_API_KEY=AIzaSyC-your-actual-api-key-here
   ```
3. **Save the file**

### Step 3: Restart the Backend

```bash
# Stop the current backend (Ctrl+C in the terminal)
# Then restart:
cd python-backend
python app.py
```

### Step 4: Verify Integration

Run the test script to verify Gemini is working:
```bash
python test_gemini_integration.py
```

You should see:
- ✅ Google Gemini API is properly configured
- 🤖 Gemini-generated content with detailed responses

## 🔄 Fallback System

### Automatic Fallback
If Gemini is not available (no API key, network issues, etc.), the system automatically falls back to:
- **Local AI Processing**: Template-based intelligent responses
- **Educational Content**: High-quality study materials
- **Reliable Operation**: 100% uptime regardless of external services

### Fallback Indicators
- Health check shows: "Using local fallback system"
- Shorter, template-based responses
- "Generated by local AI" in content

## 🔒 Security Notes

### API Key Security
- **Never commit API keys** to version control
- **Use environment variables** for configuration
- **Rotate keys regularly** for security
- **Monitor usage** in Google AI Studio

### Rate Limits
- Gemini has usage quotas and rate limits
- The system automatically handles rate limiting
- Falls back to local processing if limits exceeded

## 🛠️ Troubleshooting

### Common Issues

1. **"API key not configured"**
   - Check that GEMINI_API_KEY is set in `.env`
   - Verify the key is correct (no extra spaces)
   - Restart the backend after changes

2. **"Gemini request failed"**
   - Check internet connection
   - Verify API key is valid and active
   - Check Google AI Studio for quota limits

3. **"Using fallback system"**
   - This is normal when API key is not configured
   - System continues to work with local processing
   - Configure API key to enable Gemini features

### Debug Mode
Enable debug logging by setting:
```
FLASK_ENV=development
```
