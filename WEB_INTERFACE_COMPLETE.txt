🚀 HOW TO USE
==============================================================

1. START BACKEND:
   cd python-backend
   python app.py

2. START FRONTEND:
   npm start

3. ACCESS APPLICATION:
   http://localhost:3000

4. LOGIN AS TEACHER:
   Username: demo_teacher
   Password: teacher123
   ID: 100

5. CREATE ASSIGNMENT:
   - Click "Create Assignment"
   - Add questions
   - Assign to students

6. VIEW EXAM OVERVIEW:
   - Click "Overview" button next to any exam
   - See class statistics
   - Analyze question performance
   - View all submissions

7. EVALUATE SUBMISSIONS:
   - Click "Evaluate" on any submission
   - Grade answers
   - Provide feedback
   - Submit evaluation
